Authority ends. The data leaves.

Each agent gets authority for one task. While it works, its data sits in this machine's memory, and the bars show the kernel's own page counts. When the task is done or you revoke it, its work is saved, its memory is released, and a signed receipt says so. Check the receipt yourself, right here.

A receipt appears when an agent's authority ends.
Page counts come from /proc/self/pagemap on this machine, sampled four times a second. Signatures are checked in your browser (Ed25519, WebCrypto) against the key at /key. This is a demo: the supervisor that grants and revokes is the demo server, not production CAPPO, and the signing key was created when it started. The same data is available as JSON at /state and /receipt/<id>.
